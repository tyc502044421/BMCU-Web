说明

  • 在线刷写通过 Web Serial 实现 WCH ISP 协议（与 bmcu_flasher.py --mode usb 同源），自动进 Bootloader，无需按键。
  • 若浏览器不支持 Web Serial，请用 Python 版：python bmcu_flasher.py firmware.bin --mode usb
  • 固件文件可在本仓 firmware/ 或 GitHub Releases 下载。
